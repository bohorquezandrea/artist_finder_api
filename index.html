Python · Flask · Spotify Web API

Artist Finder API

API REST que gestiona usuarios y sus artistas favoritos, y consulta informacion real de artistas y canciones contra la Spotify Web API. Nueve endpoints, persistencia en JSON y autenticacion por client credentials contra Spotify.

PythonFlask RESTSpotify Web API OAuth client credentialsJSON
Esta pagina es la referencia, no la API corriendo. GitHub Pages solo sirve archivos estaticos: no puede ejecutar Python. Para probarla de verdad, clona el repositorio y levantala en local con flask run, o desplegala en un servicio que ejecute Python. Las credenciales de Spotify van en un .env y nunca se publican.

Usuarios

CRUD completo sobre users.json.

POST/users

Crea un usuario. Devuelve 400 si falta name o email.

// peticion
{ "name": "Juan Carlos", "email": "jc@example.com" }

// 201 Created
{ "message": "Usuario creado con éxito",
  "user": { "id": 1, "name": "Juan Carlos",
            "email": "jc@example.com", "artists": [] } }
GET/users

Lista todos los usuarios registrados.

// 200 OK
[ { "id": 1, "name": "Juan Carlos",
    "email": "jc@example.com", "artists": ["Coldplay"] } ]
GET/users/<id>

Un usuario por id. 404 si no existe.

PUT/users/<id>

Actualiza nombre o email. Los campos son opcionales.

// peticion
{ "name": "Juan C. Perez" }
DELETE/users/<id>

Elimina el usuario y persiste el cambio.

Artistas favoritos

Lista de artistas asociada a cada usuario.

POST/users/<id>/artists

Anade un artista a los favoritos del usuario.

// peticion
{ "artist_name": "Coldplay" }

// 201 Created
{ "message": "Artista agregado con éxito",
  "artists": ["Coldplay"] }
GET/users/<id>/artists

Devuelve los favoritos de ese usuario.

Spotify

Consulta en vivo contra la Spotify Web API. El token se pide con client credentials en cada llamada.

GET/spotify/artist/<nombre>

Busca un artista y devuelve generos, seguidores y popularidad.

// 200 OK
{ "name": "Coldplay",
  "genres": ["permanent wave", "pop"],
  "followers": 48250119,
  "popularity": 89,
  "url": "https://open.spotify.com/artist/...",
  "image": "https://i.scdn.co/image/..." }
GET/spotify/song/<nombre>

Busca una cancion: album, fecha de lanzamiento, duracion y popularidad.

// 200 OK
{ "name": "Yellow",
  "artist": "Coldplay",
  "album": "Parachutes",
  "release_date": "2000-07-10",
  "duration_ms": 266773,
  "popularity": 88 }

Levantarla en local

Necesitas credenciales de una app de Spotify for Developers.

git clone https://github.com/bohorquezandrea/artist_finder_api.git
cd artist_finder_api
pip install -r requirements.txt

# crea un .env con tus credenciales
echo "SPOTIFY_CLIENT_ID=tu_id" >> .env
echo "SPOTIFY_CLIENT_SECRET=tu_secreto" >> .env

python app.py   # http://127.0.0.1:5000
