Para quien venga a ver el código

El proyecto original es una API REST en Flask con nueve endpoints y autenticación por client credentials contra la Spotify Web API. GitHub Pages solo sirve archivos estáticos y no ejecuta Python, así que esta página replica la lógica del backend contra localStorage.

La playlist se arma con un catálogo local y un criterio de afinidad por género: dos temas de cada artista elegido y cuatro de artistas que comparten género con ellos. Con el servidor encendido, esas mismas canciones vendrían de GET /spotify/artist/<nombre>.
